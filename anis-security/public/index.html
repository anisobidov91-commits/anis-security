Anis Security

Ёвари амнияти телефон: файл, пайванд, парол ва барномаҳо.

Санҷиши файл

Файл дар телефони шумо мемонад ва ба ҷое фиристода намешавад.

Санҷиши пайванд

Пайванд кушода намешавад ва ба ҷое фиристода намешавад. Танҳо шакли он таҳлил мешавад.

Санҷиши парол

Парол танҳо дар ҳамин саҳифа таҳлил мешавад. Агар шубҳа дошта бошед, паролҳои воқеиро ин ҷо нанависед.

Санҷиши барномаҳои насбшуда

Барномаҳои бегона (на аз мағозаи расмӣ) ва иҷозатҳои хатарнокро меёбад.

Дар бораи Anis Security

Кор мекунад: ҳаши файл, аломатҳои пайванди шубҳанок, қувваи парол ва санҷиши барномаҳои насбшуда дар Android. Ҳама дар худи телефон.

Намекунад: вирусро худкор нест намекунад ва ҳамларо намебандад. Натиҷа танҳо огоҳӣ аст, на кафолат. Қарор ҳамеша бо шумост.

Санҷиши барномаҳо: барномаҳое, ки аз Google Play насб шудаанд, камтар шубҳанок ҳисоб мешаванд. Барномаи ҳалол низ метавонад огоҳӣ гирад, масалан барномаи паёмрасон бо иҷозати SMS.

Баъдтар: огоҳии push, санҷиши пароли фош шуда ва пойгоҳи вирусҳо. Барои ин сервер ё калиди API лозим аст.

Маслиҳат: Google Play Protect-ро фаъол нигоҳ доред, APK-ро танҳо аз сарчашмаи боварӣ насб кунед ва 2FA-ро фаъол кунед.
