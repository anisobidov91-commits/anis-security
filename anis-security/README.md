# Anis Security (нусхаи 2)

Барномаи хурд барои муҳофизати телефони Android. Ҳама таҳлил дар худи телефон анҷом меёбад.

## Дар ин нусха чӣ нав аст
- **Бахши «Барномаҳо»:** рӯйхати барномаҳои насбшударо мехонад ва онҳоеро нишон медиҳад, ки на аз мағозаи расмӣ насб шудаанд ё иҷозатҳои хатарнок доранд (SMS, рӯйпӯш, насби APK, дастрасии махсус, администратори дастгоҳ). Рангҳо: хатарнок, эҳтиёт, дуруст.
- Тугмаи **«Намуна»** тарҳро бо маълумоти намунавӣ дар браузер нишон медиҳад.
- Намуди нав: таъсироти графикӣ (радар, нур, ҳаракати пасзамина). Агар дар телефон «кам кардани ҳаракат» фаъол бошад, таъсирот хомӯш мешавад.
- Тамоми интерфейс бо тоҷикӣ (кириллӣ).

## Чӣ тавр навсозӣ кунед (GitHub)
1. Папкаи `anis-security`-ро аз зип кушоед ва ба саҳифаи upload-и репозиторӣ кашед. Файлҳои кӯҳна иваз мешаванд.
2. Файли `.github/workflows/blank.yml`-ро бо матни нав иваз кунед (матнро дар чат додаам).
3. Пас аз 5-10 дақиқа дар қисми **Releases**-и репозиторӣ файли `Anis-Security-debug.apk` пайдо мешавад.

## Дар ин ҷо чӣ санҷида шуд
| Санҷиш | Натиҷа |
|---|---|
| Синтаксиси `app.js`, `risk.js`, `sw.js` | гузашт |
| Қоидаҳои хатар: 6 намунаи барнома (`risk.js`) | ҳама гузаштанд |
| Скрипти `build-android.sh` (`bash -n`) | синтаксис дуруст |
| Скриптҳо ва услубҳои inline, `eval`, `innerHTML` | нест (CSP-и қатъӣ мувофиқ аст) |
| Сервери маҳаллӣ: ҳамаи файлҳо | 200 OK |

**Санҷида нашудааст:** коди Java-и плагин (дар ин ҷо `javac` ва Android SDK нест), сохтани APK ва кори скан дар телефони воқеӣ.

## Маҳдудиятҳо
- Ин антивирус нест. Он огоҳ мекунад, қарор бо шумост.
- Санҷиш танҳо аломатҳоро (манбаи насб, иҷозатҳо) мебинад, на коди барномаро. Барномаи ҳалол низ метавонад огоҳӣ гирад.
- Барои дидани рӯйхати ҳамаи барномаҳо иҷозати `QUERY_ALL_PACKAGES` илова мешавад. Google Play ин иҷозатро маҳдуд мекунад, пас барои нашр дар Play бояд сабаб навишт. Барои насби шахсӣ мушкил нест.
- Огоҳии push, санҷиши пароли фош шуда ва пойгоҳи вирусҳо ҳанӯз нест.

## Сохтани APK дар компютери худ
```
npm install
bash scripts/build-android.sh
```
Лозим: Node.js, JDK 21 ва Android SDK (бо Android Studio).
